# FreeLLMAPI integration

EVONCHAT's authenticated AI assistant can route requests through a self-hosted
FreeLLMAPI instance. The browser still calls `/api/ai/chat`; the unified key is
used only by the server and must never be exposed with a `NEXT_PUBLIC_` prefix.

## Required production variables

- `FREELLMAPI_BASE_URL`: the public HTTPS URL of the router. The root URL,
  `/v1` URL, and full `/v1/chat/completions` URL are all accepted.
- `FREELLMAPI_API_KEY`: the unified `freellmapi-...` bearer key generated by
  the FreeLLMAPI dashboard.
- `FREELLMAPI_MODEL` (optional): defaults to `auto`; profiles such as
  `auto:smart` may be used when configured on the router.

For local development, a typical base URL is `http://localhost:3001/v1`.
Do not use that value in Vercel: a serverless deployment cannot reach a router
running on a developer computer. Production requires a publicly reachable
router with persistent storage and HTTPS.

After adding or changing the Vercel variables, redeploy EVONCHAT. The model
picker exposes the router as **FreeLLMAPI Auto** only when both required values
are present. DeepSeek and OpenRouter remain available and the default model
remains DeepSeek until FreeLLMAPI is verified.

FreeLLMAPI aggregates upstream free tiers. It does not provide an SLA, and each
upstream provider's terms, quotas, privacy policy, and availability still apply.
