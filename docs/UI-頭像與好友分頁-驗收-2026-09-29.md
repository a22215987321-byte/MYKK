# 頭像入口與多好友分頁驗收

## 本次修改

- 預設頭像入口與「上傳頭像圖片」並排；展開後才顯示原有頭像編輯器。
- 放大的工作區分頁列預設隱藏；向下捲隱藏、向上捲顯示，不必回到頂端。支援滾輪、觸控、鍵盤及捲軸拖曳，避免程式自動捲動造成反覆收合。
- 每位好友有獨立分頁、訊息訂閱、草稿和上傳狀態。可沿用拖曳操作移往另一方塊；關閉一頁不影響其他頁。
- 文字、附件與貼圖發送固定綁定原好友 UID；沿用既有 Firestore 路徑、訊息格式和權限。只清除實際可見好友頁的未讀數。
- 非作用中對話不留下浮動附件／表情選單。
