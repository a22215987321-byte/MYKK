- 最新完整測試為 23 組、203 項通過，TypeScript 通過，相關檔案 lint 無錯誤（既有 Hook warnings 保留）。
- 本次顏色／文字微調依專案規則不重跑本機 build；前一輪完整 UI／帳號流程的 production build 已通過，推送後由 Vercel 編譯正式版本。

## 帳號切換說明

新增帳號時保留原帳號的 Firebase session，其他已登入的帳號能直接恢復。
不保存密碼，也不把 token 塞進帳號顯示清單。最多保留八個帳號，登出會清除
目前帳號的保存登入，其他帳號不受影響。登入狀態遭撤銷、過期、瀏覽器清除資料，
或只有舊版帳號顯示紀錄時，仍需要重新登入一次。

Firebase 參考：[Auth.updateCurrentUser](https://firebase.google.com/docs/reference/js/auth.auth)、
[登入持續性](https://firebase.google.com/docs/auth/web/auth-state-persistence)。
